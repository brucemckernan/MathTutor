1 · The Dimensional Ladder Start Here

Every integral in this course lives at exactly one rung of a dimensional ladder. The subscript on ∫ tells you which rung. The differential tells you what kind of infinitesimal chunk you're summing.

⚠ The single most confusing notation clash
dS (lowercase italic) = scalar area element (a positive number, like ds for arc length)
dS or dS⃗ (bold / vector) = vector surface element = n dS (a vector pointing outward)
Context and bold-font are your only clues. When in doubt: if it's inside F·dS, it's the vector one.

Key insight: T and n are unit vectors built into the differentials
dr = T ds — the tangent unit vector times arc length
dS = n dS — the unit normal times surface area
So F·dr = F·T ds (work = tangential component × length) and F·dS = F·n dS (flux = normal component × area)

Divergence Theorem

Fundamental Theorem for Line Integrals

Conservative field: F = ∇f ∫C F·dr = f(b) − f(a)
1D integral → 0D boundary values

Requires: F = ∇f (conservative). Path doesn't matter, only endpoints. If C is closed: result = 0.

Green's Theorem

2D region D, boundary ∂D = C (counterclockwise) ∮C P dx + Q dy = ∬D (∂Q/∂x − ∂P/∂y) dA
1D line integral = 2D area integral of curl

Requires: D flat (in xy-plane), C simple closed counterclockwise, F smooth on D.
∂Q/∂x − ∂P/∂y = (curl F)·k = the z-component of curl.

Stokes' Theorem

Surface S in ℝ³, boundary ∂S = C (right-hand rule) ∮C F·dr = ∬S (curl F)·dS
1D line integral = 2D surface integral of curl F

Green's theorem is Stokes' with S being a flat region in the xy-plane!
If curl F = 0 everywhere, then ∮C F·dr = 0 for any closed C.

Divergence Theorem (Gauss's)

Volume E, closed boundary surface ∂E = S (outward normal) ∯S F·dS = ∭E div F dV
2D flux integral = 3D volume integral of div F

If div F = 0, total flux out of any closed surface is 0 (incompressible flow).
Use when direct surface integral is hard but volume integral is easy (or vice versa).

The Operator Ladder: gradient → curl → divergence
The derivative that appears in each theorem follows a fixed pattern:

∇f (gradient of scalar → vector)  ·  FTC for line integrals
curl F = ∇×F (of vector → vector)  ·  Green's & Stokes'
div F = ∇·F (of vector → scalar)  ·  Divergence Theorem

And note: div(curl F) = 0 always, curl(∇f) = 0 always — these are the "boundary of a boundary = 0" identities.

5 · Conservative Vector Fields — Special Cases

What makes a field conservative?
F = ∇f for some scalar potential f (equivalently: curl F = 0 on a simply-connected domain)

Conservative field

  • ∫C F·dr depends only on endpoints
  • ∮C F·dr = 0 for any simple closed curve C
  • curl F = 0 (irrotational)
  • Find f by integrating: ∂f/∂x=P, ∂f/∂y=Q, ∂f/∂z=R
  • Use FTC: ∫C F·dr = f(end) − f(start)
  • Green/Stokes gives 0 = 0 (trivially true)

Non-conservative field

  • ∫C F·dr depends on path
  • ∮C F·dr ≠ 0 in general
  • curl F ≠ 0 (has rotation)
  • Use Green's/Stokes' to convert hard loop integral to easier area integral
  • Closing a path can simplify: split C = C₁ + (−C₂) where C₂ is easy

Simple closed curves in non-conservative fields (using Green's)

SituationApproachResult
∮C F·dr, C counterclockwise around D Green's: convert to ∬D (Qx−Py) dA Area integral, often much easier
∮C F·dr, C clockwise Reverse orientation: add minus sign −∬D (Qx−Py) dA
curl F = 0 but domain has hole (e.g. F = (−y,x)/(x²+y²)) Domain not simply connected! curl=0 doesn't imply conservative ∮ = 2π × (winding number around hole)
Area of region via Green's A = ½ ∮C x dy − y dx Clever use: P=−y/2, Q=x/2, Qx−Py=1

6 · Parameterisation — Getting to dt or du dv

You always integrate in parameter space. The scaling factor converts parameter area/length to geometric area/length.

Curve parameterisation r(t), t ∈ [a,b]

IntegralConverts to
∫C f ds∫ab f(r(t)) |r′| dt
∫C F·dr∫ab F(r(t))·r′(t) dt
Trivial reparameterisation
If you replace t with s=φ(t) (same curve, different speed), the integral is unchanged as long as direction is preserved. Reversing direction flips sign of F·dr but not ∫f ds.

Surface parameterisation r(u,v), (u,v) ∈ D

IntegralConverts to
∬S f dS∬D f(r(u,v)) |rᵤ×rᵥ| du dv
∬S F·dS∬D F(r(u,v))·(rᵤ×rᵥ) du dv
Cross product is your scaling factor
rᵤ × rᵥ is perpendicular to the surface and its magnitude = area stretch factor.
For scalar: take |rᵤ×rᵥ|. For vector flux: keep (rᵤ×rᵥ) as a vector — it encodes both area and orientation.

Common non-parameterised / shortcut forms

Surface typeScalar dSVector dS (upward)
z = g(x,y) over D dS = √(1 + gₓ² + g_y²) dA dS = (−gₓ, −g_y, 1) dA
x = g(y,z) over D dS = √(1 + g_y² + g_z²) dA dS = (1, −g_y, −g_z) dA
Sphere ρ=a (spherical coords) dS = a² sin φ dφ dθ dS = a² sin φ r̂ dφ dθ
Cylinder r=a (cylindrical) dS = a dθ dz dS = a r̂ dθ dz

7 · Mnemonics & Memory Aids

🧵 The Wire / Shell / Solid analogy

Scalar integrals = weighing things:
• Wire (1D) with density f → ∫C f ds
• Shell (2D surface) with density f → ∬S f dS
• Solid (3D) with density f → ∭V f dV

f=1 always gives total length/area/volume.

💧 Flow analogies

Vector integrals = measuring flow:
• Work = flow along curve → ∫C F·dr (tangential)
• Flux = flow through surface → ∬S F·dS (normal)

Work cares about the tangential component.
Flux cares about the normal component.

📐 Differential sizing rule

Lowercase scalar: always a magnitude, always positive
ds, dS (italic), dA, dV

Bold/vector: has direction, can be negative
dr, dS (bold)

Parameter: geometric meaning only after multiplying by the scaling factor
dt, du dv

🔄 Boundary orientation memory

Green's: walk CCW around D, region stays on your LEFT.
Stokes': curl your right hand fingers in direction of C; thumb points in direction of n on S.
Divergence: normal on ∂E always points outward from the volume.

⬆ Which theorem to reach for?

Hard closed curve integral in 2D → Green's (become area integral)
Hard closed curve integral in 3D → Stokes' (become surface integral)
Hard closed surface flux integral → Divergence (become volume integral)
F = ∇f? → FTC: just evaluate f at endpoints

🔑 The "∂" unifier

Every theorem:    ∫∂Ω = ∫Ω (d-operator)

• ∂C = two endpoints; d-op = gradient
• ∂D = closed curve; d-op = 2D curl
• ∂S = closed curve; d-op = 3D curl
• ∂E = closed surface; d-op = divergence

Dimension of ∂Ω = dimension of Ω minus 1.

Quick-reference: "What is my differential telling me?"
dt → I'm in 1D parameter land, haven't accounted for curve speed yet
ds → I have true arc length; the speed |r′| is baked in
dr → I have a directed vector; dotting with F gives tangential work per unit length
dA / dx dy → I'm integrating over a flat 2D region
du dv → I'm in 2D parameter land, haven't accounted for surface stretching yet
dS (scalar) → I have true surface area; |rᵤ×rᵥ| is baked in
dS (vector) → I have an oriented surface element; dotting with F gives normal flux
dV → I'm integrating over a 3D region
